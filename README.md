# 🎮 Tic-Tac-Toe Game in C

A simple console-based **Tic-Tac-Toe game** developed using the **C programming language**. This project demonstrates fundamental programming concepts such as arrays, functions, loops, conditional statements, user input, and game logic.

## 📌 Project Description

The Tic-Tac-Toe Game is a two-player console application played on a 3×3 board.

Player X starts the game, followed by Player O. Players take turns entering the row and column where they want to place their symbol. The program validates each move, checks for a winner after every turn, and determines whether the game ends in a draw.

## 🚀 Features

- 🎮 Two-player gameplay
- ❌ Player X
- ⭕ Player O
- 🧩 3×3 game board
- ✅ Valid move checking
- 🏆 Automatic win detection
- 🤝 Draw detection
- 🔄 Automatic player switching
- 🖥️ Simple console interface
- ⚡ Lightweight and easy to understand
